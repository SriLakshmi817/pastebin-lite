# Pastebin Lite

A simple Pastebin-like application built with Next.js.

Users can create text pastes and share a URL to view them.
Pastes can optionally expire based on time (TTL) or number of views.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Vercel KV (Redis) for persistence

## Run Locally

```bash
npm install
npm run dev
